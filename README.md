# Sonora 声之旷野 · V9

真实可播放的音乐 RPG 网页原型。包含单色骑士、奶油色复古 CRT、差异化地形地图、每日探索收获卡和音乐小怪兽支线。

## GitHub 在线体验

公开源码：https://github.com/kirahook/sonora-music-rpg 。发布地址：https://kirahook.github.io/sonora-music-rpg/ （首次部署成功后生效）。手机、平板和电脑直接打开同一链接即可体验；各浏览器存档独立，不会自动同步。官方试听需要网络，本地音频不上传。

`.github/workflows/pages.yml` 在 main 更新后自动构建、运行 38 项测试并发布到 GitHub Pages。仓库 Settings → Pages 的 Source 需选择 GitHub Actions。构建使用 `PAGES_BASE_PATH=/<仓库名>/`，JS/JSON 与 CSS 素材一起适配子路径；本机与既有 Sites 的默认路径仍为 `/`。请只发布 `dist/client`，不要部署本地开发服务器。

## 保留的世界与探索玩法

- 地图上的「奇闻」图钉进入区域交战。回声斩为强力攻击，守拍轻击并减伤；每只小怪兽首次战胜奖励 90 XP。
- 六片海域拥有六种不同的小怪兽：偷拍鸦、磁带水母、灯蛾摆渡人、云眠兔、余烬吉他蜥、极光海豹。各有不同形象、共鸣值、反击强度、故事和装备礼物。
- 24 段奇闻 / 支线、24 张独立漫画插画，按区域分为金黑爵士报刊、青蓝科幻、紫灰暗夜、粉彩童话、锈红朋克和冰蓝极地六种风格。每区四个顺序章节：听 1 首 → 听 2 种流派 → 听 3 张专辑，奖励 150 / 220 / 300 XP、1 / 2 / 3 碎片，终章赠区域装备，随后番外听两种流派得 240 XP / 4 碎片。实际聆听 20 秒（短曲 80%）才推进任务，重复阅读不发奖。
- 首页有武器、护具、旅途饰物三个装备槽。24 件装备，初始可选 10 件；拥有后才可穿戴。武器改变交战伤害，护具减伤；夜航斗篷、罗盘、花信披风、极光灯笼使每日基础聆听/查阅经验额外 +4% / +8% / +10% / +15%。6 碎片强化一级。
- 每日收获按本次结算经验分四档，各有独立封面与回馈：旅人 1–299、探险家 300–899、领航者 900–1799、传奇 1800+ XP。依次获得 1 / 1 / 2 / 3 钥匙、1 / 1 / 2 / 3 强化和 1 / 3 / 6 / 10 基础碎片，以及档位装备；重复装备转为额外 4 碎片。当天可重读，次日刷新清单。
- 保留每日探索委托和三曲远征。旧存档不清除，已领的旧版结算不追补或重复发奖。23 张新增原创美术素材由内置 Image Gen 生成，最终文件与完整提示词见 `v6-asset-prompts.md`。

## 体验

1. 终端自动开机；电源键可关机和重新启动，关机会立即暂停音频。KNIGHT / MUSIC 切换角色与音乐界面；可选择绿色、琥珀、冷白荧光色并调节亮度。
2. 内置 30 张专辑共 367 个 Apple 官方试听地址，增加放克、世界音乐、碎拍、合成器、Dubstep、民谣、金属、雷鬼和古典等风格。点击曲目或 PLAY 即可真正播放，支持暂停、上一首/下一首、同专辑连续播放、拖动进度、音量与静音。外部音源需要网络，可能受地区或资源变更影响。
3. IMPORT AUDIO 可选择多个本地 MP3、M4A、AAC、WAV、OGG、FLAC 文件；具体格式以浏览器解码能力为准。文件不上传，可播放完整时长；刷新或关闭页面后需要重新选择。
4. 唱片架支持滚轮循环漫游、鼠标悬停/键盘焦点信息框、搜索与流派筛选。30 张精选唱片循环展示，不是无限远程音乐数据库。
5. 有效播放 20 秒计入一次聆听；短于 25 秒的音轨需实际播放 80%。跳转进度本身不计入有效播放时长；每首每日只计奖一次。查阅每张专辑每日计一次。
6. 每日结算：聆听 ×120 XP + 查阅 CD ×30 XP + 首次发现流派 ×180 XP + 饰物加成；每 2000 XP 升一级。四档奖励以本次总经验判定，战报展示计算。每日领取一次，领取后的新活动仍可推进奇闻和委托，但不再进入当天结算清单。
7. 初始角色为 LV.4 / 7420 XP，3 片已发现海域、1 枚探索钥匙。点击下一片迷雾海域，消耗钥匙解锁。地图可放大并横向滚动，进度保存在当前浏览器。
8. 音乐向导提供基于心情与流派的本地规则推荐，尚未连接大模型。

官方试听不等于完整商业专辑串流；完整专辑提供 Apple Music 链接。本地完整音频播放不受试听片段限制。当前是前端原型，无账号、云端同步或服务端防作弊。

## 本地开发

Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
npm run build
node --test --test-concurrency=1 tests/*.test.mjs
```

预览：`http://127.0.0.1:4173/`。构建输出为 `dist/client`；既有 Sites 打包入口保持完整。当前任务已启动本机预览。

## 结构与来源

- `src/App.jsx`：界面、循环唱片架、开关机、地图与战报。
- `src/usePlayer.js`：真实 HTML audio、播放列表、本地文件、实际播放计量。
- `src/progression.js`：可测试的计奖、结算与迷雾解锁逻辑。
- `src/audio-catalog.json`、`src/extra-audio-catalog.json`、`src/extra-albums.json`：Apple 公开目录的官方试听元数据和扩充目录。
- `scripts/fetch-tracks.ps1`：从各专辑官方目录更新试听元数据。
- `public/assets/cover-sources.json`、`extra-cover-sources.json`：30 张专辑封面的原始来源；`scripts/expand-catalog-v6.ps1` 负责新增目录更新。
- `src/FieldNotes.jsx`、`src/encounters.js`：六怪兽交战、24 段奇闻、收获卡与漫画收藏。
- `src/Armory.jsx`、`src/equipment.js`、`src/Wardrobe.jsx`、`src/wardrobePose.js`：24 件装备、独立穿搭及手套遮挡层、分武器握点、战斗/结算属性与四档收获。
- `src/QuestGarden.jsx`、`src/v7.css`：每日像素花园、鼠标/键盘交互、像素装备与穿搭布局。
- `public/assets/dot-icons.png`、`crt-bezel.png`、`world-relief.png`、`knight-pixel.png`：生成式美术素材；地图是立体风格图像与网页交互层，不是可旋转的 3D 引擎。
- `src/MusicHandbook.jsx`、`src/handbook.js`、`src/v8.css`：流派历史手账、跨日收藏与比例修复。
- `src/SoundLandscape.jsx`、`src/soundHistory.js`、`src/v9.css`：六类聆听地形、逐日真实记录、单页手账与握持样式。
- `design-qa.md`：本轮视觉与交互验收记录。
- `scripts/make-audio-fixture.mjs`：测试用短音频生成器，测试音频不包含在公开网页资源中。

旧版 `music-sea.png` 和早期参考素材保留作历史资源，新界面不使用旧地图。
