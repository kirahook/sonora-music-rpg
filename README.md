# Sonora 声之旷野 · V25

真实可播放的音乐 RPG 网页原型。包含单色骑士、奶油色复古 CRT、差异化地形地图、每日探索收获卡和音乐小怪兽支线。

## GitHub 在线体验

公开源码：https://github.com/kirahook/sonora-music-rpg 。发布地址：https://kirahook.github.io/sonora-music-rpg/ 。手机、平板和电脑直接打开同一链接即可体验；各浏览器存档独立，不会自动同步。官方试听需要网络，本地音频不上传。

`.github/workflows/pages.yml` 在 main 更新后自动构建、运行全部测试并发布到 GitHub Pages。仓库 Settings → Pages 的 Source 需选择 GitHub Actions。构建使用 `PAGES_BASE_PATH=/<仓库名>/`，JS/JSON 与 CSS 素材一起适配子路径；本机与既有 Sites 的默认路径仍为 `/`。请只发布 `dist/client`，不要部署本地开发服务器。

## V24 先听一段，再认识世界

- 旅人指南首次入口改为四步：选一张真实唱片、亲手播放、记录一个听觉特点、展开声音札记。不再要求出发前先读完装备／地图／任务／手账；原九章保留为随用随看的功能手册。已完成或跳过的旧指南不会强制再次弹出，旧阅读位置继续保留。
- 聆听时提供节拍、音色、空间与留白等注意方向，允许选择「暂时还没辨清」。这是自己的感受，不是听力考试或音频识别。仍沿用真实播放20秒／短曲80%的校验，拖动进度不能替代播放；装载唱片不自动播放。
- 新的前两项每日委托分别要求「听过并留下线索」和「记录两种流派、再比较一个相似或不同」，奖励仍为手动领取60／120 XP；第三项三张专辑、远征、奇闻及结算规则不变。旧版当天已经积累的资格和已领取奖励保留到次日刷新，不会被新条件突然锁回。
- 第一张声音札记保存在本浏览器，次日仍可重看，不覆盖原手账笔记；展开本身不发经验、不消耗钥匙，也不自动解锁迷雾海域。界面复用现有唱片、信笺、邮戳和双语像素标题，沿用手机及展开屏适配。
- V24完成时108项测试与根路径／Pages子路径构建通过；四步引导已做真实试听、线索、比较、手动领奖及桌面／手机截图检查。本次随V25一起发布，检查范围及真机限制见本地 `design-qa.md`。

## V23 手机与展开屏适配

- 原 WEB 共用同一套页面、画面和存档逻辑，没有另做原生应用或按设备型号分流。窄屏保留单列阅读，减少首页留白和底栏占高，补足表单字号与触控空间。
- 701–1024 CSS 像素宽度采用展开屏布局：CRT 与真实曲目队列并排，单行随行导航，海域说明／结算双栏、拾音场景／调频双栏、旅伴横向阅读、三列漫画和双栏闪卡。更宽的桌面布局保留。
- 适配安全区、动态视口弹窗及短横屏。输入框统一16px；文本输入且可视高度明显缩小时隐藏随行底栏，退出后恢复，不中断播放、不修改存档。
- 101项测试及根路径／Pages 子路径构建通过。320–960宽度、844×391横屏和1440桌面已做浏览器尺寸检查，无整页横向溢出；手机指南、展开屏城市及卡牌已实际截图检查。以上为浏览器模拟，不是 iPhone Safari 真机或折叠铰链认证。最后一轮截图服务出现前台读取失败，完整范围与证据见本地 `design-qa.md`。

## V22 旅伴来信

- 地图右栏新增「旅伴来信」：复用六位伙伴的原有像素画像，提供18封原创世界观短信、寄信地点与声音标签。手动「换一封来信」循环翻阅；各海域当前页记住翻阅位置，刷新后回到首封。

## V19–V21 装饰频道、海域行前卡与海上拾音

- 声音中场保留原有奶油白／青绿色 CRT 外壳，增加森林、午夜城市、晶体、花园、潮汐和极地六组缓慢变化的原创装饰场景，加上原彩条共七个虚构频道。支持手动换台、暂停、减少动态、离屏与后台停止；不播放音频，不分析当前音乐，不发放经验。

- 首页像素背景采用连续流场，支持潮汐、轨道与编织变化、暂停和减少动态；原有标题与文字对比度保留。

- 装备条目补充来历、实际获取来源与数值；每日账单展示逐项计算和信物，已领取的战报始终读取原收据。漫画已收藏与未收集状态分别使用完整着色与灰阶预览。
- 世界地图上下增加真实航行进度和可切换海域档案：钥匙、已测绘海域、共鸣相遇、漫画收藏与六种虚构世界设定。查阅档案不会消耗钥匙；未知海域仍需明确确认、依次解锁。
- 保留中英双标题与已有像素/哥特字，功能正文使用本地托管的 Space Grotesk / Noto Sans SC。统一优化手机、平板、横屏、引导、地图、闪卡、战报与触控按钮，保留原有账号边界和浏览器独立存档。
- 本版82项规则与组件测试通过，根路径和 GitHub Pages 子路径构建通过。组件测试使用独立的服务端渲染配置，不启动客户端预热或依赖扫描。已做320/392px手机、平板和横屏的浏览器交互/布局测量；截图服务仍不可用，最终截图视觉验收及真实 iOS/Android 设备验证未完成。部署成功不代表逐像素视觉认证。

## 体验

1. 终端自动开机；电源键可关机和重新启动，关机会立即暂停音频。KNIGHT / MUSIC 切换角色与音乐界面；可选择绿色、琥珀、冷白荧光色并调节亮度。
2. 内置 30 张专辑共 367 个 Apple 官方试听地址，增加放克、世界音乐、碎拍、合成器、Dubstep、民谣、金属、雷鬼和古典等风格。点击曲目或 PLAY 即可真正播放，支持暂停、上一首/下一首、同专辑连续播放、拖动进度、音量与静音。外部音源需要网络，可能受地区或资源变更影响。
3. IMPORT AUDIO 可选择多个本地 MP3、M4A、AAC、WAV、OGG、FLAC 文件；具体格式以浏览器解码能力为准。文件不上传，可播放完整时长；刷新或关闭页面后需要重新选择。
4. 唱片架支持滚轮循环漫游、鼠标悬停/键盘焦点信息框、搜索与流派筛选。30 张精选唱片循环展示，不是无限远程音乐数据库。
5. 有效播放 20 秒计入一次聆听；短于 25 秒的音轨需实际播放 80%。跳转进度本身不计入有效播放时长；每首每日只计奖一次。查阅每张专辑每日计一次。
6. 每日结算：聆听 ×120 XP + 查阅 CD ×30 XP + 首次发现流派 ×180 XP + 饰物加成；每 2000 XP 升一级。四档奖励以本次总经验判定，战报展示计算。每日领取一次，领取后的新活动仍可推进奇闻和委托，但不再进入当天结算清单。
7. 初始角色为 LV.4 / 7420 XP，3 片已发现海域、1 枚探索钥匙。点击下一片迷雾海域，消耗钥匙解锁。地图可放大并横向滚动，进度保存在当前浏览器。
8. 音乐向导提供基于心情与流派的本地规则推荐，尚未连接大模型。

官方试听不等于完整商业专辑串流；完整专辑提供 Apple Music 链接。本地完整音频播放不受试听片段限制。当前是前端原型，无账号、云端同步或服务端防作弊。
